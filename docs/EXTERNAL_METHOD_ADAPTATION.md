# Critical adaptation of external design methods

**Status:** optional documentation candidate. **Baseline:** public main `d06de12240413693b5f37ae9a2fe4303b0573cc2`, architecture 3.6.0. Existing pilot classifications and proposed ADR statuses remain unchanged.

The maintainer's direction is to evolve this framework by comparing useful external ideas with actual gaps. A reference is neither a replacement operating system nor product authority. Preserve a sufficient existing method; adapt an idea when its contribution is concrete; defer it when cost, rights or evidence do not support adoption.

## First bounded adaptation

This batch provides an original [method-selection guide](DESIGN_METHOD_ENTRYPOINTS.md), an optional [component behavior seed](../runtime/docs/templates/COMPONENT_BEHAVIOR.md), a [fictional behavior specification](../examples/component-behavior/README.md) and a [decision-brief example](examples/DECISION_BRIEF.md). These materials were written for the existing evidence/authority model. No upstream code, file or substantial prose block is vendored or translated into the package.

## Rights and what remains deferred

Designer Skills has an explicit [MIT license](https://github.com/Owl-Listener/designer-skills/blob/9a6930cf84a822eb458624bd11c61aac5bbdf224/LICENSE), copyright MC Dean. AI Product Design Team for Claude has an explicit [MIT license](https://github.com/sharadsonkarwork/AI-Product-Design-Team-for-Claude/blob/f935948f4289c780cbbbccf07de712f896ef150a/LICENSE), copyright Sharad Sonkar. These are reference terms for their material, not a relicensing of this framework. A future literal/substantial import must identify the exact covered assets, retain their required copyright/license notices, record modifications and check separately licensed dependencies. Our existing licenses and attribution remain intact.

Baraldi declares MIT in its [package metadata](https://github.com/leobaraldi96/fwbaraldi/blob/efd409c1f2a9b59a480bca13089ac9e3abae2a80/package.json), while its [README](https://github.com/leobaraldi96/fwbaraldi/blob/efd409c1f2a9b59a480bca13089ac9e3abae2a80/README.md) combines CC BY 4.0/MIT wording. No separate LICENSE/COPYING/NOTICE file was found in the inspected tracked snapshot. This is a documentation ambiguity, not a conclusion that no permission exists. Literal reuse is deferred pending asset-specific clarification; the current contribution is critical analysis with source attribution.

Full plugin marketplaces, Engram or other memory services, provider-specific agents, universal health scores, fixed review-round limits and scheduled design-debt audits are outside this adaptation. GOV-VAL-001 already covers proportionate validation; knowledge/retrieval and cause triage also have existing contracts. Retain their evidence limits rather than duplicating mechanisms or accepting external efficiency claims. The prior index trial's no-savings finding is unchanged.

## Compatibility and acceptance

Only the new unconfigured seed enters the existing package inventory as configured/project-owned when populated. It is discovered on demand and does not join bootstrap_files. Existing configured private seeds/history must not be overwritten; private adoption is a separate governed change. This batch changes no Master/JSON policy, runtime state/schema, dependency pin, compatibility alias, license or existing ADR status.

Acceptance for the documentation candidate: the guide distinguishes relevant situations without bypassing startup/authority; the seed/example covers allowed, denied, known failure and unresolved outcome recovery; the brief points to existing owner records and cannot grant broader approval; sources/limits are explicit; package/privacy/protected-file checks and immutable changed-file readback pass. The PR record reports actual QA, including any setup failure. Static checks and manual documentary review are neither executed component behavior nor independent human/product acceptance.

Existing [ADR-0025](decisions/ADR-0025-pilot-maturity-and-promotion.md), additive-seed compatibility in [ADR-0028](decisions/ADR-0028-traceable-methodology-audit.md) and adopted [GOV-VAL-001 / ADR-0029](decisions/ADR-0029-risk-proportionate-validation.md) provide the current boundaries; this adaptation accepts no proposed ADR or new mandatory policy. [Hosted CI](HOSTED_CI_STATUS.md), merge, release, pilot promotion and private adoption retain their separate gates. No new trial is implied by adding a guide.
