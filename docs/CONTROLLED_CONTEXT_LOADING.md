## Acceptance and migration

Run current package, synchronization, methodology/catalog, onboarding, state and contextual-reader regressions. Review changed contents and all public privacy/rights boundaries; bind remote readback to the exact candidate. Local Windows PASS is not hosted execution. Existing manual suspension and historical release exceptions do not transfer to this candidate. Publication and downstream adoption require their own actual evidence/authority.

After a released immutable source exists, compare installed declared source, actual shared files and target. Preserve configured values, unknown fields, historical decisions/Sessions/reports, product statuses, operator scope and report cursors. Reconcile shared divergence before replacement. A private-only metadata correction need not wait for a generic release; reusable shared evolution follows public release/pin adoption.

Keep legacy full bootstrap and exact rollback sources. Revert only migration-owned selections/tooling/current records, preserving later unrelated work. Independent fresh-chat authority/delivery/QA/handoff trials remain NOT RUN until actually executed and attributed; subprocess tests do not establish AI compliance or production acceptance.
