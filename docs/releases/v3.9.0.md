## Evidence and caveats

Each feature PR has operator-attributed local Windows/Python 3.12.10 nine-step package QA applicable to its **own** exact SHA, with clean-worktree readbacks. PR #23 through #25 explicitly retain **one symlink subtest SKIPPED** on the restricted Windows host; hosted CI has **no verified execution**. A release candidate changes Master, derivative, README, validator, ADR index and release metadata, so it requires **its own nine-command exact-SHA QA and changed-file readback**; prior feature checks are not a substitute. Independently verified long-running AI recovery, third-party tool provenance, hosted Linux behavior and optional-method efficiency/production gains are not established by these fixtures.

Licensing remains PolyForm Noncommercial 1.0.0 (software-like) and CC BY-NC 4.0 (documentation), unchanged and non-OSI. The public-source and rights review must confirm no client/private context or uncompensated external material is transferred. Historical experiments, negative findings and seven `OPTIONAL_PILOT` statuses remain intact. ADR-0025 and ADR-0032 stay PROPOSED. Neither integration nor a public release automatically adopts a project profile or approves workstream results.
