## Added and improved

- Provider-neutral AI-assisted installation/configuration guidance, explicit immutable source selection and fictional onboarding/fresh-process regression tests.
- Accepted GOV-VAL-001 / ADR-0029: validation proportional to risk, reuse of still-valid evidence, protected mandatory criteria and closure limited to the evidenced deliverable.
- Generic evidence/delivery, Design System QA and methodology guidance, a bounded 35-topic catalog and traceable documentary transfer checkpoint.
- Optional method-selection guide, component-behavior template, fictional failure/recovery specification and derived decision brief, with pinned external attribution and reuse limits.
- Reproducible fictional QA tools, scoped experiment reports, a downloadable human-reading packet and native annotation/layout observations with documented caveats.
- Current-package, synchronization, methodology, catalog and onboarding checks; generic evidence-ingestion and optional local transcription guidance.

## Compatibility and adoption

The package retains the v3.6 runtime architecture, startup intents and mandatory bootstrap order, inventory paths, runtime schemas/states, configured project values and compatibility aliases. Framework version, installed runtime version and schema versions remain independent. No populated project data is included and no installed runtime updates automatically.

Before adopting, verify the actual released immutable commit and follow the [synchronization procedure](../FRAMEWORK_RUNTIME_SYNC.md). Compare the installed declared source, actual shared files and target. Reconcile local shared-file divergences, review new configured seeds, preserve unknown extensions/history and obtain project-specific migration approval. Keep a rollback source.

## Maturity and known limits

GOV-VAL-001 is accepted operating policy. ADR-0024–0028 and ADR-0030 remain PROPOSED; their supplemental guidance and experimental material are distributed with that status. The seven optional pilots retain their classifications. A release does not accept proposed decisions or validate pilot effectiveness.

- Human comprehension, individual native annotation collapse/expanded occupancy and cross-file published-library adoption remain unverified.
- Fifteen earlier local fictional functional cases do not establish production identity, authorization or product acceptance. The later component-specification cases B1–B8 are NOT RUN.
- Eight-session synthetic retrieval observations showed approximately 18.6% more case-source bytes and no avoided case-document reads. No token/cost saving or productivity gain is claimed. The delivery-efficiency comparison remains DEFERRED.
- AI-assisted onboarding is not a clean-machine or cross-provider acceptance result. Earlier live core evidence remains scoped to its original environment/revision.
