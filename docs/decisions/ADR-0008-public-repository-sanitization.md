# ADR-0008 — Keep the public repository free of client-specific context

**Date:** 2026-10-05  
**Status:** `ACCEPTED`  
**Scope:** `GOVERNANCE`

## Context

The framework originated through real consulting work, but it is intended to become reusable across many projects and possibly evolve into a consulting product.

## Decision

The public repository must contain only generic framework material, templates, sanitized examples, and fictitious references.

No real client names, stakeholders, proprietary URLs, node IDs, evidence, or work packages should be published.

## Why

The framework should be portable without leaking consulting-client information.

## Impact

Client confidentiality and product generality are both preserved.
