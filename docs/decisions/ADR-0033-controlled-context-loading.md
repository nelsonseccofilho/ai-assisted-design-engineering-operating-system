# ADR-0033 — Controlled contextual reading with preserved normative sources

Date: 2026-10-21. Status: ACCEPTED for implementation and Git consolidation by explicit maintainer authorization. Scope: optional generic method and compatibility; no private data or product authority.

## Context and evidence

Long-lived runtimes can mix stable rules, current state and accumulated history. Multiple representations and presence-only checks can hide inconsistent routing. More text or a smaller prompt alone does not prove compliance. The maintainer authorized a controlled refactor after audit and critical comparison, preserving obligations and authorization criteria.

## Decision

Add optional GOV-CTX-001 and a read-only reader using existing manifest/package/Workstream architecture. Keep Master text and mandatory default00–70, existing schema/enums/templates and compatibility mirrors. A project may adopt an explicit index-plus-context plan without deleting original normative text or historical evidence. All omitted normative sections require contextual routes. Modules remain applicability pointers, not competing rules or a new task/status store.

Select work by actual intent/scope; never file/operator/ACTIVE alone. Explicit current routes align registry/state/action. Distinguish distribution, normative adoption, observed integration and behavioral evidence. Fix exhaustive inventory classification of the existing comments procedure. Extend focused regression evidence; do not claim independent AI/operator compliance from local fictional processes.

## Preservation, validation and rollout

Version preparation3.8.0 is compatible opt-in distribution. No existing runtime adopts automatically. Preserve exact source paragraphs, conditional force, exceptions, privacy, ownership, decision rationale, reporting and acceptance gates. Validate full package, source/alias parity, complete section routing, meaningful negative cases and readback. Keep default behavior available; scoped configuration rollback preserves later unrelated history.

Public PR integration, publication and private adoption remain separate recorded actions. Existing hosted suspension and release-specific exceptions do not supply new hosted PASS or future waiver. Bind any release to its exact reviewed source and actual required evidence. No live or productivity claim; independent fresh-chat testing remains separate until actually observed.
