# ADR-0003 — Use “AI-Assisted Design Engineering” as the practice name

**Date:** 2026-10-05  
**Status:** `ACCEPTED`  
**Scope:** `FRAMEWORK`

## Context

“AI Design Engineer” is an emerging and inconsistent job title, while “Design Engineer” is more established.

## Decision

Use **AI-Assisted Design Engineering** as the name of the practice. Treat **AI-Assisted Design Engineer** as a useful working description, not a universal standardized job title.

## Why

The framework describes a method of work more reliably than it defines a market-standard role title.

## Impact

The project can evolve without depending on a still-changing job taxonomy.
