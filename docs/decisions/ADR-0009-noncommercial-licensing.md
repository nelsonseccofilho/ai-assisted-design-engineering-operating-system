# ADR-0009 — Adopt noncommercial public licensing with commercial rights reserved

**Date:** 2026-10-05  
**Status:** `ACCEPTED`  
**Scope:** `LICENSING`

## Context

The framework is intended to be publicly available for study, experimentation, research, and noncommercial use while preserving the possibility of commercialization through consulting, products, training, or separate licensing.

## Decision

Use:

- PolyForm Noncommercial License 1.0.0 for framework/software-like materials;
- CC BY-NC 4.0 for documentation/editorial material;
- a separate commercial licensing notice reserving commercial use.

## Why

This supports public learning while preserving commercial rights for the copyright holder.

## Impact

The repository is source-available for noncommercial use, not OSI Open Source.
