# ADR-0025 — Preserve maturity and scope during methodology promotion

**Date:** 2026-10-15
**Status:** PROPOSED
**Scope:** framework promotion review

## Context
An operator-approved experiment, a narrowly successful retrieval test, static geometry, functional correctness and product acceptance are different evidence. Promoting them together can turn incomplete pilots into mandatory rules.

## Decision
Classify each finding as existing core, narrowly verified, operationally adopted, pilot pending or project only. Keep public claims within the observed validation scope and distinguish attributed evidence from newly reproduced results. Publish generic pilot guidance for review without adopting private geometry, product roles or tool-cost claims.

Pilot acceptance requires scoped criteria, actual representative execution, recorded limits and accountable review. Required bootstrap, authority and security gates remain. Optional automation does not waive acceptance criteria. Candidate implementation, release and private pin adoption are separate operations.

## Consequences
The review is useful before all pilots pass, while the PR remains Draft. Later promotion needs evidence and a separate governed decision. No retrospective compliance or automatic cross-product policy transfer is inferred.

## Validation
Fictional positive and negative promotion scenarios check that a pending or merely adopted policy cannot claim end-to-end validation, that verification requires evidence and review, and that project-only material stays excluded. Static tests do not validate the real pilots.

## Supersession
None.
