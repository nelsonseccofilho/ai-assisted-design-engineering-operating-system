# ADR-0034 — Scoped local evidence during maintained hosted suspension

Date: 2026-10-21. Status: ACCEPTED by explicit current maintainer instruction. Scope: reviewed3.8.0 controlled-refactor Git consolidation/publication and its actual evidence conditions only.

## Authority and observed limits

The maintainer explicitly directed keeping Static QA disabled until the reported account limitation is resolved and requested local testing with online Git review/approval. The existing workflow definition remains inspectable and is not re-enabled. This is a new scoped decision, not reuse of ADR-0031 or proof that ADR-0022 runner-zero criteria were freshly observed. Hosted execution for this candidate is NOT RUN; local Windows PASS is never hosted Linux PASS.

## Conditions

Require all current workflow-equivalent local steps, affected integrity/preservation/negative regressions, full-content privacy/rights review and immutable remote readback for the actual candidate. Record setup/harness failures and conditional skips accurately. Bind the online PR and publication receipt to the final commit/tree and those results; any material payload change requires affected verification and renewed evidence binding. Keep independent fresh-chat trials, fictional subprocess tests and live/product behavior separate.

Current user authorization covers controlled implementation and Git consolidation. This scoped decision permits the reviewed3.8.0 publication path after its conditions are met; it does not approve an untested payload, waive any other binding gate, invent execution, accept unrelated proposed ADRs/pilots or authorize private/product/Figma changes. Downstream adoption retains its own recorded scope and preservation checks.

## Suspension and expiry

Keep hosted automation disabled until explicit maintainer reactivation. No polling, scheduled reactivation or paid work is introduced. This exception applies only to the reviewed3.8.0 consolidation payload; it is not a future-release waiver. Normal hosted evidence should replace non-execution when authorized and available. Preserve all historical failures and exceptions.

## Ownership and validation

Owner: public framework; history CHANGELOG.md; online PR/readback records actual immutable identity. Require local QA and publication/privacy checklist, with source-qualified limitations in release notes. No confidential account or project details belong in this public record.
