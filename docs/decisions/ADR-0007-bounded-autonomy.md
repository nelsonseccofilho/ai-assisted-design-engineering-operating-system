# ADR-0007 — Use bounded autonomy based on risk and reversibility

**Date:** 2026-10-05  
**Status:** `ACCEPTED`  
**Scope:** `GOVERNANCE`

## Context

Requiring confirmation for every small action creates unnecessary friction, while unrestricted autonomous mutation creates systemic risk.

## Decision

Allow autonomous execution for low-risk, well-evidenced, reversible work. High-impact work requires additional impact analysis, QA, and documentation.

## Why

Autonomy should scale with confidence, impact, and reversibility.

## Impact

The workflow remains efficient without sacrificing control over systemic changes.
