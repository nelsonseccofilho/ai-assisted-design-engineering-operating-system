## First delivery: comparison protocol and local kit

Four planned sessions per regime balance case order and index availability. The [recorded trial](RETRIEVAL_COMPARISON_2026-10-15.md) completed those eight fresh AI sessions and sixteen scoped observations. Correct recovery and explicit index use were observed; source payload increased by about 18.6%, with no demonstrated efficiency benefit. This is exploratory evidence, with zero human participants.

The preparation command produces only fictional inputs. It does not create chats, recruit people, use a paid API or change any private runtime. Mechanical tests check setup, accounting, source preservation and exclusion gates. Their PASS is tooling evidence, not independent-session validation.

Source correctness, annotation/decision authority and permissions remain primary. A reduction in reader bytes is not token or financial savings. No index use gives no index-efficacy evidence. Missing participant resources should result in an incomplete trial or a newly versioned protocol before execution.
