# Workstreams

Canonical populated path:

`workstreams/WS-YYYYMMDD-NNN-<slug>/`

Each Workstream contains `HANDOFF.md` and `state.json`.

An optional, unreleased [typed-state/current-handoff proposal](../docs/contracts/CURRENT_STATE_AND_HANDOFF.md)
supports explicitly declared extensions and a separately selected current handoff.
Existing projects keep their current routing until their owner approves a scoped migration.
