# Human documentary handoff packet

**Packet version:** v1.1, external-reader instructions. **Language:** Brazilian Portuguese.
**Human trial:** NOT RUN; no participant response is recorded in this package.

This optional fictional packet supports a small human comprehension exercise for the existing handoff/review pilots. It is not a configured Project Runtime, a substitute for mandatory operational bootstrap, a working application or a complete framework usability study. Architecture and released version remain 3.6.0; no pilot maturity changes.

## Read online

Start with [INICIAR_AQUI.md](participant/INICIAR_AQUI.md). It links the four scenario documents and asks eight questions. The reader should return their first complete response privately to the person who provided the packet, including source references, prior familiarity, exposure to answers and any assistance. No GitHub account is needed to read a public packet; do not post personal responses in a public issue or PR.

## Preserve the first attempt

Do not provide expected answers or the coordinator's AI assessment before the first response. Re-reading the supplied sources is allowed. If the reader asks for substantive explanation or receives assistance, retain that fact and the first response; do not count the assisted condition as an unaided trial. A lack of information may be reported as such.

The [trial documentation](../../docs/HUMAN_HANDOFF_TRIAL.md) records the scope, preparation acceptance, version history and evidence limits without publishing the answer key. Any broader claim needs its own representative evidence and accountable review. No new participants, chats, messages, editor changes, paid services or releases are created by this kit.
