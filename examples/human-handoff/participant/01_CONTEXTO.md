# Contexto — cenário fictício

O **Acervo de Cartões** é um produto inventado apenas para este exercício. A tela permite procurar cartões de exemplo e apresenta uma mensagem quando não há resultados.

## Artefato e referência

- Artefato em revisão: `BOARD-EXAMPLE-01`, tela “Lista de cartões”.
- Componente de referência: `Card/Base`, da biblioteca fictícia “Biblioteca Exemplo”.
- O artefato possui uma nota contextual local. A existência da nota não altera o componente compartilhado.
- O protótipo é uma representação local; não está conectado a um serviço de publicação.

## Responsabilidades no cenário

- A pessoa que recebe este handoff prepara um parecer documental.
- `PROD-EXAMPLE` é o papel fictício responsável pelo aceite de produto.
- A governança da biblioteca decide sobre mudanças compartilhadas.

Os nomes, papéis e identificadores deste pacote são inventados. Não há arquivo real de produto ou biblioteca para alterar. Estes arquivos são materiais de leitura, não um Project Runtime instanciado.
